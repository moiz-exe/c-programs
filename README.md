## `01 // THE MISSION`

Welcome to my programming workspace.

This repository contains C and C++ source files from my programming practice, including small exercises involving character codes, calculations, loops, and basic mathematical operations.

It's a record of learning by writing code, experimenting with ideas, and improving problem-solving skills.

**The mission:** understand the logic behind the code, not just memorize the syntax.

## `03 // GETTING STARTED`

### Clone the repository

```bash
git clone https://github.com/moiz-exe/c-programs.git
cd c-programs
```

### Compile a C program

Install GCC through a suitable toolchain, such as MinGW-w64 on Windows.

```bash
gcc main.c -o main.exe
```

Run it in the terminal:

```powershell
.\main.exe
```

### Compile a C++ program

For example, to compile `cube.cpp`:

```bash
g++ "cube.cpp" -o cube.exe
```

Run it:

```powershell
.\cube.exe
```

**Note:** Some existing files may need corrections before they compile. Each source file should be checked independently. C and C++ are different languages and should be compiled with the appropriate compiler.
